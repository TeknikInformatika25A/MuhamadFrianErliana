# Portofolio Muhamad Frian Erliana

Website portofolio personal branding mahasiswa S1 Teknik Informatika, Universitas Perjuangan Tasikmalaya. Dibuat dengan HTML, CSS, dan JavaScript tanpa framework.

## Struktur

- `index.html` : isi dan struktur halaman
- `style.css` : tampilan, termasuk tema terang dan gelap
- `script.js` : tombol tema, menu aktif, dan data pribadi di bagian `PROFIL`

## Cara menjalankan

Buka `index.html` di browser. Tidak perlu instalasi apa pun.

## Cara mengisi data pribadi

Buka `script.js`, lalu isi bagian `PROFIL` di baris paling atas:

- `email` : email yang mau ditampilkan
- `linkedin` : alamat profil LinkedIn
- `foto` : nama file foto (taruh di folder yang sama)
- `cv` : nama file CV berformat PDF (taruh di folder yang sama)

Bagian yang dikosongkan tidak akan tampil di halaman.

## Cara menayangkan

Aktifkan GitHub Pages lewat Settings, Pages, Deploy from a branch, pilih branch `main` dan folder `/ (root)`.
